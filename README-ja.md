# upmix3d

[English](README.md) | 日本語

VLC（Windows 64bit版）用の音声出力モジュールです。ステレオや5.1chなどの音声を、ハイトスピーカー（天井や壁の高い位置に置くスピーカー）を含む最大7.1.4chのスピーカー構成に広げて再生します。

## 動作環境

- Windows 10（バージョン1703以降）またはWindows 11、64bit
- VLC 3.0.x 64bit版
- ハイトスピーカーを使う場合：Windowsの空間サウンド（Dolby Atmos for home theater等）が使える出力機器
- ビットストリーム出力を使う場合：HDMI等で接続したAVアンプ

## インストール

1. VLCを終了します。
2. `libupmix3d_plugin.dll`を、VLCのインストールフォルダーにある`plugins\audio_output\`へコピーします。
3. VLCを起動し、［ツール］→［設定］→［オーディオ］の［出力モジュール］で「upmix3d 空間アップミックス出力」を選び、［保存］を押します。VLCを英語で使っている場合は「upmix3d spatial upmix output」と表示されます。
4. ハイトスピーカーを使う場合は、Windowsのサウンド設定で出力機器の空間サウンドを有効にします。

## 設定

VLCの［ツール］→［設定］で、左下の［設定の表示］を［すべて］にし、［オーディオ］→［出力モジュール］→［upmix3d］を開きます。変更した設定は、次に再生を始めたときに反映されます。

| 設定 | 内容 |
| --- | --- |
| 出力構成 | お使いのスピーカー構成を選びます。既定は5.1.2です |
| モノラル・ステレオ音声のプリセット、マルチチャンネル音声のプリセット | 音の広げ方を、入力音声のチャンネル数ごとに「映画」「音楽」「音楽（ワイド）」「カスタム」から選びます。既定はモノラル・ステレオが「音楽」、マルチチャンネルが「映画」です |
| ビットストリーム出力 | Dolby DigitalやDTSなどの音声を、そのままAVアンプへ送るかどうかを選びます。送っている間はVLCの音量が効かないため、AVアンプで調整してください |
| カスタムプリセット（モノラル・ステレオ）、カスタムプリセット（マルチチャンネル） | プリセットを「カスタム」にしたときに使う値です。モノラル・ステレオ用とマルチチャンネル用で別々に持ち、初期値はそれぞれ「音楽」「映画」と同じです。台詞をセンタースピーカーにどれだけ寄せるかや、サラウンド・ハイトの音の大きさなどを調整できます |
| 音割れ防止 | 大きな音での音割れを防ぐ方法を選びます。既定の「リミッター」のままで構いません |
| 空間サウンド・共有出力・ビットストリーム出力の遅延補正 | 映像と音がずれるときに調整します |

すべての設定を初期値に戻すには、［次回のVLC起動時にすべての設定を初期値に戻す］をオンにして［保存］を押し、VLCを起動し直します。

## 困ったとき

- **［出力モジュール］に表示されない:** VLCが64bit版か（64bit版は`Program Files (x86)`ではなく`Program Files`の下にインストールされます）と、DLLをコピーした場所が`plugins\audio_output\`かを確認し、VLCを再起動してください。
- **ハイトスピーカーから音が出ない:** Windowsのサウンド設定で、出力機器の空間サウンドが有効になっているか確認してください。
- **ビットストリーム出力ができない:** ほかのアプリが音を出していないか確認してください。また、「サウンドの設定」→［サウンドの詳細設定］→ 出力機器のプロパティ →［詳細］タブで、「アプリケーションによりこのデバイスを排他的に制御できるようにする」をオンにしてください。

設定どおりに出力できないときは、原因と対処がVLCの画面に表示されます。
