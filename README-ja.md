# upmix3d

[English](README.md) | 日本語

VLC（Windows 64bit版）用の音声出力モジュールです。ステレオや5.1chなどの音声を、ハイトスピーカー（天井や壁の高い位置に置くスピーカー）を含む最大7.1.4chのスピーカー構成に広げて再生します。

## 動作環境

- Windows 10（バージョン1703以降）またはWindows 11、64bit
- VLC 3.0.x 64bit版
- ハイトスピーカーを使う場合：Windowsの空間サウンド（Dolby Atmos for home theater等）が使える出力機器
- ビットストリーム出力を使う場合：HDMI等で接続したAVアンプ

## インストール

1. VLCを終了します。
2. `libupmix3d_plugin.dll`を、VLCのインストールフォルダーにある`plugins\audio_output\`へコピーします。
3. VLCを起動し、［ツール］→［設定］→［オーディオ］の［出力モジュール］で`upmix3d`を選びます。
4. ハイトスピーカーを使う場合は、Windowsのサウンド設定で出力機器の空間サウンドを有効にします。

## 設定

VLCの［ツール］→［設定］で、左下の［設定の表示］を［すべて］にし、［オーディオ］→［出力モジュール］→［upmix3d］を開きます。変更した設定は、次に再生を始めたときに反映されます。

| 設定 | 内容 |
| --- | --- |
| 出力構成（Output layout） | お使いのスピーカー構成を選びます。既定は7.1.4です |
| プリセット（Preset） | 音の広げ方を「映画」「音楽」「音楽（ワイド）」から選びます |
| ビットストリーム出力（Bitstream passthrough） | Dolby DigitalやDTSなどの音声を、そのままAVアンプへ送るかどうかを選びます。送っている間はVLCの音量が効かないため、AVアンプで調整してください |
| センター抽出・センター幅（Center extraction、Center width） | 台詞などの中央の音を、センタースピーカーにどれだけ寄せるかを調整します |
| サラウンド・ハイトのレベル（Generated side / back level、Height level） | 広げた音の大きさを調整します |
| 保護方式（Level protection） | 大きな音での音割れを防ぐ方法を選びます。既定の「リミッター」のままで構いません |
| 遅延補正（Latency correction for spatial sound / shared output / exclusive output） | 映像と音がずれるときに調整します |

## スピーカーの位置を確認する

1. 設定の［upmix3d］で、［Speaker test at next playback］をオンにして保存します。
2. 好きな動画や音楽を再生します。
3. 各スピーカーから順に音が鳴り、鳴っているスピーカーの名前が画面に表示されます。［Stop］で途中でやめられます。

## 困ったとき

- **ハイトスピーカーから音が出ない:** Windowsのサウンド設定で、出力機器の空間サウンドが有効になっているか確認してください。
- **ビットストリーム出力ができない:** ほかのアプリが音を出していないか確認してください。また、「サウンドの設定」→［サウンドの詳細設定］→ 出力機器のプロパティ →［詳細］タブで、「アプリケーションによりこのデバイスを排他的に制御できるようにする」をオンにしてください。

設定どおりに出力できないときは、原因と対処がVLCの画面に表示されます。
