# システム仕様

## 構成

VLCが入力形式とレートを変換する。PCMはWG4順の最大9位置で受け取り、出力スレッドがリングから取り出してDSPを実行する。出力スレッドはCOMの初期化、ストリームの生成・制御・破棄を所有する。キュー満杯時は書き込みを待ち、停止・エラーでは待機を解除する。

| ファイル | 責務 |
|---|---|
| `src/core.cpp` | 正規化、構成判定、STFT、生成・混ぜ込み・LFE・基本レベル保護 |
| `src/profiles.cpp` | 14入力構成とプリセット値の合成 |
| `src/transport.cpp` | 圧縮形式の許可、キャリアと変換レート、バイト保持リング |
| `src/true_peak.cpp` | 4相24タップの補間FIR上限、23サンプルの先読みリミッター |
| `src/boundary.cpp` | 余弦形状の境界ゲイン |
| `src/windows_audio.cpp` | デバイス・形式交渉、空間オブジェクト、WASAPI、クロック、音量 |
| `src/vlc_module.cpp` | VLC登録・設定・コールバック、保存、イベント処理、復旧、遅延報告 |

## 信号処理

後方だけを持つ入力は側方に正規化する。ダウンミックスOFFでは入力と設定の和集合、ONでは設定した構成を出力する。機器制限による削減はログを出して混ぜ込む。

STFTはHann窓を使用し、元の音と生成音の分析遅延を合わせる。ハイトはアンビエンスの高域成分から生成し、位置ごとに独立したオールパスを用いる。LFEは入力だけを使用する。

トゥルーピーク保護は補間係数と信号の絶対値から保守的な上限を計算する。窓内でゲインが変化する場合にも上限を維持するため、閾値近くでは余裕を多めに取る。4倍補間モデルによる保護であり、EBU R 128の番組ラウドネス測定・正規化や第三者認証を意味しない。

## ビットストリーム

VLCの変換フィルターがIEC 61937へ格納し、モジュールはバイト列のまま排他WASAPIへ渡す。DSP・並べ替え・音量・フェードを適用しない。対象外形式や交渉失敗は開始時に拒否し、VLCのPCMデコードへ戻す。

| 形式 | Windowsキャリア | VLC変換用レート |
|---|---|---|
| AC-3 / DTSコア | 通常48kHz・2ch・16bit | 入力レート |
| E-AC-3 | 入力レートの4倍・2ch・16bit | キャリアレート |
| DTS-HD | 48kHz系は192kHz、44.1kHz系は176.4kHz・8ch・16bit | キャリアの4倍に相当する4バイト単位の周期 |
| TrueHD / MLP | 48kHz系は192kHz、44.1kHz系は176.4kHz・8ch・16bit | キャリアレート |

時間はキューのバイト数と実キャリアの毎秒バイト数で求める。DTS-HDの変換レートをWindowsのクロックには使わない。対応するレート系統を判定できないHBR入力はPCMへ戻す。既成のビッグエンディアンIEC入力は16bit単位でWindowsの順に直す。

## 設定・同期・再生制御

構成別指定、モノ／ステレオまたは多チャンネル指定、全体指定の順でプリセットを決める。適用値を基準として個別変更を検出し、カスタムへ移行する。値と基準はVLCの設定APIで保存する。

遅延は入力キュー、DSP内の未排出量、IAudioClockとQPCによる未再生量、経路別補正を合計する。64bitカウンターを使い、経過時間の反復加算を避ける。

一時停止では入力位置とDSPを保持し、短いフェード後に停止する。シークはキューとDSPを破棄する。排出は処理末尾を流して再生を待つ。デバイス変更・無効化はVLCに再構成を要求し、空間出力が復旧しない場合は共有WASAPIへ移行する。

## 検証素材

`tests/fixtures/`は48kHz・5.1・約3秒の無音圧縮入力。AC-3とE-AC-3は448kbps、DTSコアは768kbps、TrueHDは無音のロスレス入力。Atmosメタデータを含む素材ではない。DTS-HD検証ではDTSコアを高ビットレート形式へ格納する。

コアテストは構成・DSP・プリセット値・補間ピーク・リング・時間単位を検証する。ネイティブ結合テストはポータブルVLCを使い、設定を`build/integration/test.vlcrc`へ限定する。位置確認ツールは`--play`を指定しない限り音を出さない。
