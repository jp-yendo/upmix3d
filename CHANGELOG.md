## [Unreleased]

### Added

- Upmix mono, stereo and multichannel audio to surround layouts with up to four height speakers.
- Choose matrix or frequency-domain upmixing, dialogue protection, surround delays and height controls.
- Play through Windows spatial sound, shared WASAPI or exclusive WASAPI, with automatic fallback when an output is unavailable.
- Pass AC-3, DTS, E-AC-3, DTS-HD and TrueHD/MLP streams to a compatible receiver without changing their audio data.
- Assign presets to individual input layouts and save automatically customized presets.
- Protect output peaks with configurable attenuation, normalization or a linked true-peak limiter.
- Select audio devices, adjust latency separately for each output route, and recover audio output after device errors.
- Use smooth playback transitions and a speaker-position check for system calibration.
